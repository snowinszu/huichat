# E2E 测试——消息回退完整流程

## Description
覆盖消息回退的完整链路（UI → IPC → 数据库），确保数量提示与删除范围不回归。参见 [tasks/prd-message-revert.md](../../tasks/prd-message-revert.md) US-003。

## Acceptance Criteria
- [x] E2E 测试在一个聊天对象下添加至少 4 条消息，对中间某条消息点击「回退」，确认对话框中显示的待删除条数与实际后续消息数一致
- [x] 确认删除后，断言该消息及其之前的消息仍然存在，其后的消息全部从界面消失
- [x] 断言离开聊天页面再重新进入后，被删除的消息不会重新出现（验证是真实的数据库删除而非仅本地状态更新）
- [x] 覆盖边界场景：对话中最后一条消息不显示「回退」按钮
- [x] 测试在 CI 中运行并通过
- [x] 测试自行创建和清理所需的聊天对象与消息数据，不依赖既有数据库状态
