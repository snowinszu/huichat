# 端到端测试：智能模式完整流程

## Description
覆盖语气选择器「智能模式」的完整链路：默认选中、生成候选回复、重新生成、切换回手动语气、润色草稿。

## Acceptance Criteria
- [x] E2E 测试断言打开聊天卡片对话界面时，语气选择器默认选中「智能模式」，且"生成回复"按钮无需手动选语气即可点击
- [x] 测试点击"生成回复"，断言请求负载中语气字段为智能模式标识，返回 3 条内容不同的候选回复
- [x] 测试在候选回复上点击"重新生成"，断言重新发起一次生成请求并返回新一轮的候选内容
- [x] 测试切换到手动选择某个预设语气（如"简洁直接"），断言「智能模式」chip 变为未选中状态，且后续生成请求携带该预设语气文本而非智能模式标识
- [x] 覆盖边界场景：草稿输入区在智能模式下点击"润色"，断言润色请求携带智能模式标识并返回润色结果
- [x] 测试运行于 CI 并通过
- [x] 测试独立可重复运行，自行创建和清理所需的聊天卡片数据
