# 设置页调试导出开关与目录展示

## Description
在设置页新增"导出提示词调试日志"开关、当前导出目录的展示，以及"选择目录"/"更改目录"入口。未设置目录时禁止开启开关，避免出现"开启但无处可写"的无效状态。

来源：`tasks/prd-llm-debug-export.md` — US-003

## Acceptance Criteria
- [x] 设置页新增一个开关"导出提示词调试日志"，样式与现有"翻译非中文消息"等开关一致
- [x] 开关旁展示当前已选择的导出目录路径；未选择时显示"未设置目录"之类的占位提示
- [x] 提供"选择目录" / "更改目录"按钮，点击后调用目录选择器 IPC，选中后立即保存并刷新展示的路径
- [x] 若用户在未选择任何目录的情况下尝试打开开关，弹出提示引导其先选择目录（开关本次操作不生效，或自动触发目录选择流程），不会保存"已开启但目录为空"的无效状态
- [x] 关闭开关不清除已保存的目录路径，方便下次重新打开时无需重新选择
- [x] Typecheck/lint 通过
- [x] Verify in a browser（e.g., via the `run` skill）

## Verification Notes
在设置页新增"调试"卡片区块（`SettingsScreen.tsx`）：一个"导出提示词调试日志"开关 + 目录展示行（路径 + "选择目录"/"更改目录"按钮，超长路径用 `text-overflow: ellipsis` 截断并加 `title` 提示完整路径）。

采用"自动触发选择目录流程"这一支路径（PRD 中两种允许方案之一）：未设置目录时打开开关，会直接调用 Issue #38 的目录选择 IPC；选中后一次性保存 `debugPromptExport: true` 和 `debugExportDir` 两个字段；若用户取消选择，则弹 toast"请先选择导出目录后再开启"且开关保持关闭，不产生任何写入。已有目录时开关可直接开关，不再触发选择器；独立的"选择目录/更改目录"按钮随时可用，只更新目录路径，不影响开关状态。

用真实 Electron 应用验证（stub 主进程里的 `dialog.showOpenDialog` 模拟系统弹窗选择/取消，因为真实原生对话框无法被 Playwright 直接点击），逐一截图确认了 5 种场景：①未设置目录时开启触发选择器并一次性保存两个字段 ②关闭开关目录路径保留 ③已有目录时再次开启不重新弹出选择器 ④"更改目录"独立按钮工作正常且不影响开关状态 ⑤未设置目录时开启被取消后开关保持关闭并显示提示 toast。全部符合预期。
